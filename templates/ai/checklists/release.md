# Release checklist (skeleton — expanded by the release skill)

- [ ] `gb verify` green on the release commit; output pasted.
- [ ] Every asset has a REGISTER row with a licence that allows this release; credits screen/file lists CC BY authors.
- [ ] Export presets exist for each target; each export builds (web: Compatibility renderer).
- [ ] The exported build was run on the target and played end-to-end by the human.
- [ ] Settings: volume, fullscreen, key rebinding where promised; pause works.
- [ ] Save data from the previous release still loads (or the break is announced).
- [ ] Version number bumped; changelog written.
- [ ] Publishing (itch.io / Steam / other) approved by the human for THIS build. Never automatic.
