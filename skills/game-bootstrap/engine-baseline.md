# Engine baseline — Godot 4 defaults and conventions

The researched defaults the decision cards recommend from, and the conventions every generated repo
follows. Facts checked against the Godot documentation in the gry-wiedza knowledge base on
2026-09-25 (`node tools/gb/gb.js kb "<topic>"` to re-check) and against Godot 4.7.2 itself.

## Verified engine facts (the ones that shape the setup)
- **Web export** targets WebGL 2 and supports **only the Compatibility renderer**; single-threaded web export is the default (Godot docs: Exporting for the Web).
- **Version control**: ignore `.godot/` and `*.translation`; commit everything else, including `*.import` and `*.uid` files (Godot docs: Version control systems). Enforce LF via `.gitattributes`.
- **Git LFS** must be set up before the first binary is committed; converting later needs `git lfs migrate`.
- **Jolt Physics** is built in since 4.4 and is the default 3D physics engine for new projects (Godot docs: Using Jolt Physics). A few joint properties are unsupported — check the doc before relying on joints.
- **Physics interpolation** exists for 2D and 3D; consider it when the physics tick is lower than the display rate.
- **CLI** (measured on 4.7.2): `--headless --import` imports; `--quit-after N` runs N frames; `--check-only --script` checks one script; runtime SCRIPT ERRORs do **not** change the exit code — `gb` reads the log.

## Defaults the cards recommend
| Setting | 2D | 3D |
|---|---|---|
| Renderer | Compatibility | Forward+ (desktop only) · Compatibility if web · Mobile for phones |
| Base resolution | pixel art 320×180 (window ×4) · smooth 1280×720 | 1280×720 |
| Stretch | pixel: `viewport` + `keep` · smooth: `canvas_items` + `expand` | `canvas_items` + `expand` |
| Texture filter | pixel: nearest (+ 2D pixel snap) | default |
| Physics | Godot Physics 2D | Jolt (default for new projects) |
| Tests | GUT | GUT |

Grow `scenes/` and `scripts/` by feature (`scenes/player/`, `scenes/enemies/`) — one feature, one subtree, so parallel work does not collide.

## Godot conventions (carried into AGENTS.md)
- GDScript with static types everywhere. Movement/physics in `_physics_process`, visuals in `_process`, always × `delta`.
- Tunables are `@export` vars or Resources — the spec's tuning table maps to them 1:1.
- Call down, signal up; cross-scene events through the `Events` autoload only when two unrelated scenes need them.
- Input only via actions. Loaded Resources are shared — `duplicate()` before per-instance mutation.
- Never edit `.godot/` or hand-edit `*.import`. Godot 3 APIs (`KinematicBody2D`, `yield`, `onready var`, `move_and_slide(velocity)`) are wrong in Godot 4.

## When to deviate
Any deviation from this baseline is the human's choice from a card and gets an ADR.
