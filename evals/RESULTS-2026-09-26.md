# Eval run — 2026-09-26 (game-builder 0.11.0)

**How:** each scenario was given to a fresh subagent (Claude Sonnet, clean context, general-purpose) as a
**stand-in run**: the skill/agent files were named in the prompt as "loaded skills" instead of the plugin being
installed in a real Claude Code session, and human answers were simulated only where the scenario says so
(tagged `[SYMULOWANA ODPOWIEDŹ]`). Each worked in its own fixture folder built by a script (fresh scaffolds, planted
bugs, a Pong clone). Grading is against the scenario's `Expected (binary)`, using the agent's report **and the
artifacts on disk** (files, git history, gb reports). A subagent's list of files it read is self-reported and not
verifiable from outside — evals that depend on read order are marked accordingly.

**What this does not cover:** automatic skill triggering by the installed plugin and the SessionStart router,
other models (Opus/Haiku), repeated runs (each scenario ran once — a single PASS is not a stability claim).

## Summary
- **Final: 20 / 20 PASS.** First runs: 16 PASS, 3 FAIL (08, 09, 14), and one invalid fixture (08, run 1).
- Each FAIL was traced to the plugin, fixed, and the eval re-run on a fresh subagent:
  - 09: game-audio did not say what to do after refusing a source.
  - 08: game-test did not say where "is the phase built?" comes from.
  - 14: a read-only playtester had no way to picture a state that needs input. Fixed with `gb scenario --end-shot` and the N/A rule.
- Passing runs still surfaced plugin defects, all fixed in 0.12.0:
  - adopt wrote template defaults and a failing example test (01);
  - the brief template tripped `gb doctor` (02);
  - agents borrowed the user's git identity (01, 02) or tried to commit against the repo rule (10);
  - the screenshot compare let a 0.42 % change pass under a 1 % threshold (05);
  - `gb` ran scenarios against a stale class cache (18);
  - the evidence path was not on the Run result line (12);
  - the Tuning table was filled after coding (11);
  - the recipes README predated `gb recipe add` (19).
